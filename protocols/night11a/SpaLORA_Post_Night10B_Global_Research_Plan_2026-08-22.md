# SpaLORA Night-10B 之后的全局研究路线图

日期：2026-08-22  
版本：v1.0  
性质：项目级方法学决策与分阶段止损计划，不是实验结果。

## 1. 我现在需要知道的三件事

1. **这一步想解决什么问题**：把项目从“按模态家族调用两套既有流程”转向一个可以被证伪、可能形成原创贡献的统一学习问题，同时避免继续无边界试错。
2. **实际做了什么、位于哪一层**：保留现有数据、图、encoder 工件、聚类端和复现设施；只在 **encoder 之后、融合之前** 新增“是否接受另一模态局部信息”的证据层与拒绝路径。Night-11A 先做无标签可识别性，不做科学评分。
3. **对论文意味着什么**：当前仍属于 `LOCAL SIGNAL`，不是 `PAPER-READY EVIDENCE`。只有新机制依次通过无标签识别、真实单 seed、多 seed、现代基线和生物解释五道门，才有资格作为二区以上方法论文的核心。

## 2. 项目总判断

Night-10B 的价值是把两条历史强路线封成可复放的工程底座：

- RNA+protein 使用 `C00 = G04 + H05`；
- RNA+ATAC 使用 `F00/R02`；
- 30/30 精确重放、两条真实链路 smoke 和 checkpoint/endpoint round-trip 均闭合。

这里 `G04` 是一种空间与特征联合建图方案，`H05` 是把两个模态私有表示和融合表示形成的三个相似图等权汇总后再聚类的端点；`R02` 是使用重构与互为近邻关系学习六个冻结视图之间残差校正的适配器。

Night-10B **不是新模型**。它按 assay family（测量模态家族）选择已经冻结的 recipe（完整处理配方），因此应继续作为工程 oracle（已知可复现的参考实现）和性能参照，不能作为论文核心贡献。

项目不推倒重来。继续复用经过验证的资产，但只允许一次有明确退出条件的方法学转向。

## 3. 建议的唯一论文核心问题

> 对每个空间点、每一次跨模态信息传递，模型能否用无标签、交叉拟合的留出证据判断这次传递是否有益；当证据不足或提示负迁移时，能否明确选择零传递？

这不是整套模型的“分流器”。决策单位从“一个数据集”缩小到“一个空间点上的一条跨模态消息”。RNA+protein 与 RNA+ATAC 共用相同的证据、门控、拒绝和训练逻辑；只允许输入归一化、ATAC 降维、输入/输出 likelihood 等由 assay 统计性质必然要求的差异。

暂用描述性名称 **选择性跨模态传递**。暂不创造论文品牌名，避免在机制尚未成立前把命名误当成创新。

## 4. 最小数学对象

对于空间点 `i`，本模态表示为 `h_i^m`，另一模态产生的候选残差消息为 `delta_i^(m<-n)`：

`h_new_i^m = h_i^m + g_i^(m<-n) * delta_i^(m<-n)`，其中 `g` 在 0 到 1 之间。

门控证据来自冻结 pilot（先导表示）上的交叉拟合留出比较：

- `L_self(i)`：只用本模态预测未参与拟合的留出对象时的损失；
- `L_transfer(i)`：加入另一模态后，对同一个留出对象的损失；
- `u_i = L_self(i) - L_transfer(i)`：局部传递效用，正值表示加入另一模态更好；
- `s_i`：在特征折、图视图和固定扰动复本间的效用不稳定程度；
- `g_i = sigmoid((u_i - lambda * s_i) / T)`。

`null expert` 是零传递路径，即 `g=0` 时保留本模态表示。这里造“null expert”这个词，是为了区别普通 attention 或 mixture-of-experts：后两者往往仍被迫在非零信息源之间重新分配权重，而本方法必须能够明确拒绝这次跨模态消息。

该比较不是因果效应估计。它只是对同一留出任务的两条前向路径做成对替代比较，论文中不得使用“因果”表述。

## 5. 架构统一与 assay 差异的边界

### 允许

- RNA、蛋白和 ATAC 使用各自合理的归一化与输入变换；
- 输入投影层和重构 decoder 根据 feature space 改变形状；
- ATAC 可以使用稀疏矩阵和 LSI；蛋白可以使用其已注册预处理；
- 同一个门控公式、同一个 evidence protocol、同一个拒绝规则在两个家族中使用同一组超参数。

### 不允许

- 按数据集、组织、物种、stage、路径或历史分数选择模型；
- RNA+protein 运行一套完整算法、RNA+ATAC 运行另一套完整算法，然后把外层路由称为新模型；
- 按数据集修改门温度、阈值、loss 权重、训练轮数或聚类 head；
- 根据标签或 ARI/NMI 的结果回头修改门控证据。

## 6. 五阶段路线与硬止损

### 阶段 1：Night-11A，无标签可识别性

目标：先证明证据分数可以识别“借用另一模态有帮助”和“借用会造成伤害”，而不是直接追求聚类分数。

- 仅 A1 seed 0（RNA+protein）和 P22 seed 0（RNA+ATAC）；
- 复用真实 preprocessing、冻结 G00/G04 视图和固定聚类端；
- 在真实表示上施加预注册的局部本模态损伤和另一模态错配；
- 比较 self-only、always-transfer、uncertainty-only、selective-transfer-with-null 四条路径；
- 标签读取、ARI/NMI/Q 和第三方 benchmark 全部为 0。

止损：效用分数不能在两个家族都区分帮助/伤害，门控全开或全关，或者 proposed 路径不能同时在本模态损伤时利用另一模态、在跨模态冲突时回到 self-only，立即结束该方向。

通过 Night-11A 只代表 `LOCAL SIGNAL`，不得声称聚类改善或新方法已成功。

### 阶段 2：Night-11B，真实单 seed 科学 smoke

仅 Night-11A 通过后启动。

- A1、tonsil、D1、P22 各固定一个 seed；
- 四条候选全部训练、checkpoint reload、融合和聚类输出锁定后，标签每数据集只打开一次；
- 固定统一 endpoint，报告绝对 ARI、NMI、空间指标、胜负和运行时间；
- 不改 Night-11A 的门控公式、阈值或超参数。

止损：四个数据中相对 always-transfer 少于三个改善，macro `Delta Q` 不为正，或出现预注册的明显空间退化，不扩大 seed。`Q=(ARI+NMI)/2` 仅为项目内部综合量。

### 阶段 3：Night-11C，五 seed 小规模确认

仅 Night-11B 通过后启动。

- 四数据各五个固定 seeds；
- 主比较：完整方法 vs self-only、always-transfer、uncertainty-only、无 null 消融；
- 进入完整论文验证的最低线：macro `Delta Q >= +0.01`，worst-dataset mean `Delta Q >= -0.005`，至少三个数据集多数 seed 胜出，空间保护门通过，移除 null 后显著变差；
- 在执行前用既有方差只做一次功效复核，看到新标签后不得改门。

止损：未过即结束这条核心机制，不派生大批近邻候选。

### 阶段 4：Night-12，方法冻结后的论文证据

只有阶段 3 通过才投入：

- 1–2 个真正冻结的新外部数据，不扩大到无关 benchmark；
- 与 SMART、SpaBalance、SpaMode、SpatialCOC、CANDIES/SCIGMA 中能够按同协议复现的现代方法公平比较；
- ARI、NMI、AMI、空间连续性、跨模态保真、资源和 spot 扩展曲线；
- 机制消融、敏感性分析和不同模态家族共享参数审计。

### 阶段 5：生物学验证与写作

- 只选择与主要性能证据一致的数据做 marker、peak-gene、低丰度空间特征或区域解释；
- 低表达故事作为模型成功后的二级验证，不重新放回主损失；
- 摘要和标题不使用 SOTA，除非同协议现代基线确实支持；
- 最终交付包括代码、固定配置、公开数据说明、seed 级结果、资源与复现实验。

## 7. 可以继承与必须停止的资产

### 继续继承

- 四个核心数据、固定 seeds、spot mapping、标签防火墙；
- Night-10B family-policy 作为复现 oracle；
- C00 作为通用工程基线，F00/R02 作为 RNA+ATAC 专家上界；
- 冻结的 G00/G04 views、affinity、partition 和 checkpoints；
- H05 或预注册的统一聚类端；
- 真实端到端 smoke、原子 checkpoint、独立复算、Git lineage 和 compact delivery；
- 所有历史负结果。

### 停止投入

- 当前 QCRD；
- 根据数据集名称或历史成绩路由；
- 搜索固定图 k、固定融合权重、聚类 head 的大网格；
- 再堆 DGI、triplet、MNN、shared/private 等公开模块而没有新的风险对象；
- seed 搜索、坏 seed 删除、标签后改门和只报告胜出数据。

## 8. 资源和执行纪律

- Night-11A 只允许 2 个真实单元、3 个固定扰动复本和 4 条预注册路径；不新增数据；
- 远端总墙钟预算 4 小时，优先复用冻结视图；超过预算即停止并报告，不临时删减审计或换数据；
- 只保留一个全局正式修正周期；若正式开始后发现全局实现错误，整体作废并完整重跑，禁止只补失败 spot、条件或 seed；
- Codex 2 的更新按 P0、smoke、formal、delivery 四个节点汇报，避免逐命令叙述；
- 关键测试保留：真实 shape、真实端到端、checkpoint reload、标签防火墙、稀疏边界、基线 artifact 复用和独立汇总；不重复构造多套等价哈希审计。

## 9. 风险登记

| 风险 | 如何识别 | 处置 |
|---|---|---|
| 留出重构不代表聚类收益 | Night-11A 过而 Night-11B 失败 | 如实归为机制可识别但科学负结果，停止扩大 |
| 门控学到扰动类型而非真实冲突 | clean、target-damage、aux-conflict 分开报告，并用未参与 evidence 的 feature fold 评价 | Night-11B 不再使用人工扰动，仅检验真实数据 |
| gate 通过数据集身份泄漏 | API/AST 检查，输入仅局部证据和 assay 合法统计信息 | 任一身份路径视为实现失败 |
| 两家族维度语义不一致 | 真实 preprocessing→forward→reload→fusion→endpoint 逐 family 验证 | 不猜维度；无法闭合则停在实现失败 |
| 只是 attention 的改名 | 必须有成对留出效用、交叉拟合冻结、显式零传递和对应消融 | 缺一项就不能按该创新故事投稿 |
| 计算开销抵消收益 | 每阶段报告 wall time、GPU/CPU/RSS，阶段 3 加资源门 | 精度门通过但资源不可接受时仍不进入论文主线 |

## 10. 论文贡献的最低成立条件

只有全部满足时，才把以下内容写成主要贡献：

1. 明确定义空间点级跨模态负迁移，而不是笼统说“质量不同”；
2. 交叉拟合留出效用在两个模态家族都可识别帮助与伤害；
3. 显式零传递路径在消融中有必要性，不是普通 attention 换名；
4. 同一结构和同一关键超参数跨 RNA+protein 与 RNA+ATAC 有效；
5. 多 seed、现代公平 baseline、空间指标、资源和生物解释共同支持；
6. 没有 dataset-name routing、标签调参或 seed 筛选。

## 11. 导师汇报版

现有项目已经形成可复现的 C00 与 F00/R02 两条强工程路线，但 Night-10B 只是按测量模态家族调用不同配方，不能承担二区以上方法论文的创新。历史结果同时提示一个更具体的问题：跨模态融合并非总是有益，P22/MISAR 能获益，而部分蛋白数据会发生负迁移。下一步不再搜索更多固定模块组合，而是在同一模型中逐空间点比较“只用本模态”和“接受另一模态”对无标签留出对象的预测效用，并允许证据不足时零传递。A1 与 P22 的单 seed 无标签试验先检验这一判断机制是否能识别人工构造的帮助和冲突，失败就立即停止，因此成本和试错范围都受到限制。若通过，再依次进行四数据单 seed、五 seed 确认、现代基线和生物学验证。已有数据、图、encoder、聚类端和复现框架均继续使用，不需要推倒重来。当前结论仍只是局部信号，能否形成论文取决于新机制能否跨家族、跨 seed 且在空间和资源门下成立。
