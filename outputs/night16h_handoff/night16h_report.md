# SpaLORA Night-16H：通用结构可行域与跨证据选择

## 我现在需要知道的三件事

1. **解决的问题。** Night-16G 的严格跨研究选择在人海马上产生了 singleton（只有一个点的簇）。本轮不再扩候选库，而是先规定所有研究都必须满足同一“结构可行域”：精确 K、无空簇、无 singleton，并且每个簇在最小注册稀疏空间图上至少有一条内部边。
2. **实际做了什么。** 在候选分区已经生成并锁定之后，新增一个通用选择层。它先执行结构过滤，再比较“分子可分性冠军”和“空间拓扑冠军”：若分子冠军的空间证据不低于候选集经验中位数就采用它，否则采用空间冠军。这里的“跨证据仲裁”只是用一条固定、无数据集名称的规则在两种证据间选择，不是把标签分区做共识平均。
3. **对论文的意义。** 固定规则相对 feasible medoid（合格候选中的普通分区代表）在 4/4 研究上 ARI/NMI 双升；严格 leave-one-study-out（LOSO，整研究留出）在 3/4 明显双升，剩余黑色素瘤仅小幅回撤且无结构退化。它形成了跨研究方法开发信号，但候选库和规则设计仍来自公开 benchmark，且 consensus/空间约束已有大量先例，所以分类为 **LOCAL SIGNAL**，不是盲测、SOTA 或 paper-ready evidence。

## 严格跨研究迁移

严格 LOSO 分成三个进程边界：三项训练研究读取公开指标并写出配置；持有研究的 producer 只读候选证据；独立 evaluator 最后才读取持有研究指标。四个折叠都机械得到同一权重：分子 `0.25`、空间拓扑 `1.0`、小簇风险 `0.0`；结构可行域始终固定，未参与标签 HPO。

| 持有研究 | ARI / NMI | 最小簇 | 相对 feasible medoid ΔARI / ΔNMI | 结论 |
|---|---:|---:|---:|---|
| P22 | 0.596390 / 0.718243 | 166 | +0.081938 / +0.073324 | 明显双升 |
| MISAR | 0.535306 / 0.658265 | 125 | +0.172199 / +0.107977 | 明显双升 |
| Human hippocampus | 0.596178 / 0.585490 | 34 | +0.023443 / +0.025424 | 明显双升并消除 singleton |
| Melanoma tumour | 0.914177 / 0.838439 | 276 | −0.004653 / −0.006734 | 小幅回撤、结构非退化 |

因此最低迁移门（至少 3/4 实质双升、剩余无明显回落、4/4 无结构退化）通过。但固定规则是用本轮四研究 scout 形成的，严格 LOSO 才是训练研究与持有研究分离的证据；两者不能混写成盲测。

## 机制与对照

- feasible medoid 的 ARI/NMI 为：P22 `0.514452/0.644919`、MISAR `0.363107/0.550287`、人海马 `0.572735/0.560066`、黑色素瘤 `0.918830/0.845173`。
- 单一 minimum inertia / maximum CH 能自动找回黑色素瘤 `0.975766/0.942756`，但在 P22、MISAR、人海马上分别只有 `0.449045/0.586932`、`0.355693/0.535251`、`0.135535/0.237378`，不能作为统一规则。
- 单一 maximum spatial 在 P22、MISAR、人海马上很强，分别为 `0.587533/0.708974`、`0.534624/0.656772`、`0.596178/0.585490`，但黑色素瘤只有 `0.914177/0.838439`。
- 固定跨证据规则在前三项采用空间冠军，在黑色素瘤采用得到足够空间支持的分子冠军，因此 4/4 高于 feasible medoid。它的价值是统一选择，不是声称 inertia、空间指标或 partition ensemble 本身新颖。
- 人海马在无结构过滤时可选到更高的公开指标候选，但最小簇为 1；正式规则拒绝该病理解。其他三项 89/89 候选均满足正式结构规则，所以总体增益不只是 singleton 修复。

## 真实 P0、复现与资源

四条真实 carrier 全部通过：P22 retained/RNA/ATAC 为 `9196×64 / 9196×30 / 9196×50`；MISAR 为 `1949×64 / 1949×30 / 1949×50`；人海马为三个 `2500×64`；黑色素瘤为三个 `833×64`。每条含 6 个 start、3 个稀疏图尺度和 89 个锁定候选；dense N×N 为 0。

最终固定规则与严格 LOSO 共 8 个输出做了两次 fresh-process replay，8/8 partition SHA、candidate ID、配置和 ordered IDs 精确一致。11/11 针对性测试通过，包括 SciPy `spearmanr` 跨版本兼容、候选顺序、类别编号、零可行候选 fail-closed 和稀疏边支持。固定规则四条总 CPU wall time 为 13.83 秒，peak RSS 82.84 MiB，GPU time/peak GPU 均为 0。

## 失败与局限

1. Night-16G 的“解盆地/persistence”没有得到支持，Night-16H 不继续包装它。
2. 结构可行域是安全约束；singleton 排除本身不是方法创新。
3. 固定跨证据规则虽 4/4 高于 medoid，但每条最终仍等于某个强单轴冠军；它证明的是跨研究仲裁价值，不证明新表示学习。
4. 严格 LOSO 在黑色素瘤有不到 0.007 的双指标回撤。
5. 所有候选库都曾参与公开 benchmark 开发；下一步若继续，需要新的冻结外部研究或在更上游生成器上验证，而不是继续对这四项调规则。
6. SMODEL、SpatialESD、STCC 和 SACCELERATOR 等已覆盖 partition ensemble、空间约束或 consensus；新颖性仍需进一步收窄和碰撞论证。

## 导师汇报版

Night-16H 针对的是上一轮严格跨研究选择在人海马上产生单点小簇的问题。我们把候选是否“像一个真实空间域”写成所有研究共用的图结构可行条件，再用同一条分子—空间证据仲裁规则选最终分区。固定规则在 P22、MISAR、人海马和 Slide-tags 黑色素瘤四项上都超过普通 feasible medoid。严格整研究留出时，P22、MISAR和人海马显著双升，黑色素瘤只有小幅回撤且没有结构崩坏。人海马最小簇从 1 提高到 34，说明安全失败已经被机制性消除。不过，最终解仍来自既有候选库，且普通 ensemble/空间约束已有先例，所以目前只能定为公开 benchmark 上的 `LOCAL SIGNAL`。论文上最稳妥的表述是“通用结构可行域与跨证据选择形成了跨研究开发信号”，不能写成 SOTA 或方法已完整成立。
